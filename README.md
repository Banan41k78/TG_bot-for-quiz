# Quiz Bot - Телеграм бот для викторин

Асинхронный телеграм бот для проведения викторин с возможностью сохранения результатов и просмотра статистики.

## Возможности

- Интерактивная викторина с вопросами о Python
- Сохранение результатов в базу данных
- Просмотр истории результатов и статистики
- Возможность перепрохождения викторины
- Подробный разбор ответов после завершения

## Технологии

- **Python 3.8+**
- **Aiogram 3.x** - асинхронный фреймворк для Telegram Bot API
- **aiosqlite** - асинхронная работа с SQLite
- **SQLite** - база данных для хранения результатов
